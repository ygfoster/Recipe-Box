# Recipe Box 🍽

自分用のレシピを写真つきで保存できる、シンプルなレシピ帳アプリです。
HTML / CSS / JavaScript だけで動き、サーバーやログインは不要です。

## 機能

- 写真 + 料理名のカード一覧（追加・編集・削除）
- ジャンル（和食・洋食・中華）と種類（メイン・サイド・スープ）の2軸で絞り込み。選択肢は設定画面（右上の ≡）で追加・削除できる。お気に入り・調理時間でも絞り込めて、並び替えは6種類
- 検索と予測変換（入力中に登録済みの料理名を候補表示。ひらがな/カタカナ・全角/半角の違いを吸収。`#タグ` でタグ検索）
- 人数に合わせた分量の自動換算
- お気に入り・★評価・作った記録（日付・ひとこと・写真）
- 参考動画：YouTube の URL を貼ると料理名とサムネイルを自動入力。小窓で再生し、指で好きな位置へ動かせる。手順をタップするとその場面から再生
- レシピの共有：材料（選んだ人数分）と作り方をテキストで LINE などに送れる
- 調理モード：画面が消えない、材料と手順のチェック、「10分煮る」などからワンタップでタイマー
- 献立：3日・1週間・2週間の日付ごとに、朝・昼・晩へレシピを入れる（レシピ画面の「献立に追加」からも）。人数も献立ごとに変えられる
- 買い物リスト：献立の材料を人数分に換算して自動で合算（玉ねぎ 1個 + 1/2個 → 1と1/2個）。調味料は「家にあれば不要」として分けて表示。チェックしながら買い物でき、Mac と Pixel で同期。共有ボタンで Google Keep や LINE に送れる
- 材料・作り方・メモ（URL は自動でリンク化）
- バックアップの書き出し / 読み込み（JSON）
- ダークモード対応、スマホ対応

## 色のルール

1つの色に1つの意味だけを持たせています(定義は `style.css` の先頭)。

| 役割 | 使う場所 |
|---|---|
| ブランド色(柿色) | アプリアイコン・ログイン画面・右下の追加ボタン(アプリアイコンそのもの)だけ |
| 操作色(青) | 押せるもの:主ボタン・リンク・手順の中の再生/タイマーボタン・フォーカス |
| 選択状態(黒/白の反転) | いま選んでいる絞り込み・選択肢 |
| 状態色(緑) | 完了・材料がそろった・同期済み・画面オン |
| 注意色(黄) | 気づいてほしいこと:タイマー終了・オフラインで未同期 |
| 危険色(赤) | 取り消せない操作とエラー:削除・同期失敗・入力ミス |
| お気に入り(ピンク) | ♥ だけ |

★評価や換算した分量などの情報は、色ではなく濃さと太さで表します。

## データの保存場所

レシピはブラウザ内（IndexedDB）に保存されます。
端末やブラウザごとに別々のデータになるので、機種変更時などは「バックアップを書き出す」→「読み込む」で移行してください。

## 公開方法（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push
2. リポジトリの **Settings → Pages** で、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で使えるようになります

## ローカルで動かす

```bash
python3 -m http.server 5173
```

ブラウザで http://localhost:5173 を開きます。
