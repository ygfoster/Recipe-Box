# Recipe Box 🍽

自分用のレシピを写真つきで保存できる、シンプルなレシピ帳アプリです。
HTML / CSS / JavaScript だけで動き、サーバーやログインは不要です。

## 機能

- 写真 + 料理名のカード一覧（追加・編集・削除）
- ジャンル（和洋中など）と種類（主菜・副菜・汁物など）の2軸で絞り込み。お気に入り・調理時間でも絞り込めて、並び替えは6種類
- 検索と予測変換（入力中に登録済みの料理名を候補表示。ひらがな/カタカナ・全角/半角の違いを吸収。`#タグ` でタグ検索）
- 人数に合わせた分量の自動換算
- お気に入り・★評価・作った記録（日付・ひとこと・写真）
- 参考動画：YouTube の URL を貼ると料理名とサムネイルを自動入力。ドラッグで動かせる小窓で再生し、手順をタップするとその場面から再生
- 調理モード：画面が消えない、材料と手順のチェック、「10分煮る」などからワンタップでタイマー
- 材料・作り方・メモ（URL は自動でリンク化）
- バックアップの書き出し / 読み込み（JSON）
- ダークモード対応、スマホ対応

## データの保存場所

レシピはブラウザ内（IndexedDB）に保存されます。
端末やブラウザごとに別々のデータになるので、機種変更時などは「バックアップを書き出す」→「読み込む」で移行してください。

## 公開方法（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push
2. リポジトリの **Settings → Pages** で、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で使えるようになります

## ローカルで動かす

```bash
python3 -m http.server 5173
```

ブラウザで http://localhost:5173 を開きます。
